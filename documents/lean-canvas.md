# 庭しごと帖 リーンキャンバス

## 課題（Problem）

- 前回いつ水やり・肥料やり・剪定をしたか、記録が分散して思い出せない
- 品目ごとに次にやるべき作業と時期を見逃す
- 今月やることと、今月収穫を迎えるものがひと目で見渡せない
- 感想や振り返りが残らず、翌シーズンに活かせない
- 代替手段は紙のノート、汎用園芸アプリ、記憶頼み、自作の簡易な記録運用

## 解決方法（Solution）

- Googleアカウントでログインし、自分の品目・作業・日記を6画面で管理する
- ホーム上部に今月・期限切れのTODOと今月の収穫を表示し、下部をカレンダー・品目一覧・アーカイブ・TODOで切り替える
- 品目の基本情報・育て方メモ・開花/収穫時期、作業の予定・完了日、日記をそれぞれ登録/編集する
- 品目詳細で作業・日記のタイムラインを表示する。TODOは日付・完了状態で絞り込める
- 栽培終了はアーカイブして履歴を残し、再開できる。削除時は関連する作業・日記も削除する
- AI提案とGoogleカレンダー連携は将来の追加機能とする

## 独自の価値提案（Unique Value Proposition）

- 品目ごとに「育て方メモ＋作業履歴＋感想・振り返り＋次回やること＋収穫時期」を1か所に積み上げ、一覧トップで「今月のやること」と「今月収穫を迎えるもの」を見渡せる
- 作業予定と完了日を分けて残せるので、記録して終わりでなく、次回の作業と収穫につながる
- 利用者同士の交流や公開はせず、自分の植物の管理に集中できる

## 圧倒的な優位性（Unfair Advantage）

- 自分自身が最初の利用者なので、実際の栽培で困ったことをもとに使い勝手を改善できる
- 使うほど自分の庭固有の育成履歴がアプリ内に蓄積され、翌年以降の作業判断の根拠になる
- アーカイブしても履歴が消えず、終わった品目も含めて季節をまたいだ振り返りができる。過去の記録を次シーズンの計画に活かせる

## 顧客セグメント（Customer Segment）

- 複数の植物を育てている、家庭菜園を楽しむユーザー
- ベリー類や柑橘など育てている植物の品種が多く、庭・畑・鉢など複数の場所で育てていて記録が分散している人
- 1か月単位で作業と収穫の見通しを立てたい人
- まず自分自身が第一の利用者

## 主要指標（Key Metrics）

- 週1回以上、作業や日記の記録が続くこと
- 予定した作業をどれだけ完了できたか（完了件数・完了率）
- 今月の作業と収穫を一覧トップで把握できること
